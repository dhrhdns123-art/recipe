아직 캐치 계정이 없으신가요?

아래 캐치 페이지로 이동하여 회원가입 또는 로그인을 진행한 후, 이 신청 화면으로 돌아와 캐치ID를 입력해 주세요.

캐치 페이지 · 회원가입/로그인 안내 ↗새 탭으로 열립니다. 연결 주소는 회원가입 전용 화면이 아닌 AX 직무 역량검사 안내 페이지입니다.

캐치에서 사용하는 ID를 공백 없이 입력해 주세요. 확인 경로: 로그인 → MY홈 → MY회원정보 → 개인정보관리(회원정보 변경 탭).

안내받을 수 있는 이메일 주소를 입력해 주세요.

입력한 정보는 참여 신청 접수를 위해 담당 시트에 전달됩니다. 잘못 입력한 정보의 수정은 담당 부서에 문의해 주세요.

연결 설정 · 관리자용

Apps Script 웹 앱 배포 주소(/exec)를 입력하세요. 접수 결과는 현재 화면의 팝업으로 확인합니다.

주소를 비워 두면 입력 검증만 수행하며 시트에 저장하지 않습니다.
